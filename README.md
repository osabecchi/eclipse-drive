# ECLIPSE DRIVE(イクリプス・ドライブ)

光(SOL)と影(LUNA)の2色を切り替えて戦う、縦スクロール弾幕シューティング。
自機と同じ色の弾は吸収してエネルギーに、違う色の弾に触れるとミス。全5ステージ、5体のボスを倒すとクリア。

**遊ぶ:** https://osabecchi.github.io/eclipse-drive/

## 操作

| 操作 | キーボード | ゲームパッド | スマホ |
| --- | --- | --- | --- |
| 移動 | 矢印 / WASD | 左スティック・十字キー | 画面をドラッグ |
| 極性反転 | Z / Space / J | A | 反転ボタン(2本目の指でタップでも可) |
| バースト | X / K / C | B | BURST |
| 低速移動 | Shift | RB | — |
| ポーズ | Esc / P | START | II |

## ルールのポイント

- 自機と違う色の敵には2倍ダメージ。同じ色の敵を倒すと、吸収できる反撃弾が飛んでくる
- 同じ色の敵を3体続けて倒すと CHAIN が伸び、ボーナスが倍々に増える(最大 25,600 点)
- エネルギー10ごとにバースト。満タンの FULL BURST は威力アップ
- 星屑とスコアで機体(HALCYON / LANCE / ORBIT)と6種の強化を購入
- 難易度 NORMAL / HARD / ECLIPSE、ステージ練習、ボスラッシュ、21の実績、ステージごとのランク(S〜C)

## スマホのホーム画面にアプリとして追加する

ホーム画面に追加できる形(PWA)になっています。追加すると専用アイコンから全画面で起動し、一度開いたあとはオフラインでも遊べます。

- iPhone: Safari で上の URL を開き、共有ボタン →「ホーム画面に追加」
- Android: Chrome で開き、メニュー →「ホーム画面に追加」(または「アプリをインストール」)

縦画面で遊ぶのがおすすめです。

## ファイル構成

ビルドは不要です。`index.html` を開くとそのまま遊べます。

- `index.html` — 画面とメニュー
- `js/` — core(入力・セーブ・音)、data(機体・ステージ・実績)、game、bosses、render、ui、main
- `manifest.webmanifest` / `sw.js` / `icons/` — ホーム画面アプリ用
- 進行状況はブラウザーの localStorage(`eclipse-drive-save-v1`)に保存されます
